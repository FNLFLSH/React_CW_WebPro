# React CW - WebPro Assignment

A React app I built to practice React fundamentals. Features a clean blue-themed UI with three interactive components.

## Features

**HelloWorld** - Simple greeting component that displays "Hello World!" with an optional name prop.

**Counter** - Interactive counter that starts at 5. Click the button to increment the count. Uses React state management.

**FilteredList** - A produce list with two filtering options:
- Search bar to filter by name
- Dropdown menu to filter by type (All, Fruit, or Vegetables)
- Both filters work together to show matching results

## Tech Stack

- React 19.2.0
- Vite
- React Bootstrap
- Bootstrap

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:5173/` to see the app.
